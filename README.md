# Todo List App

A simple and interactive Todo List application built with Vanilla JavaScript using modular architecture and DOM manipulation.

## Features

* Create projects
* Add tasks
* Edit tasks
* Delete tasks
* Mark tasks as completed
* Task detail modal
* Dynamic priority styling
* Responsive UI

## Built With

* HTML5
* CSS3
* Vanilla JavaScript
* Webpack
* Material Design Icons

## What I Learned

This project helped me understand how larger JavaScript applications are structured. I practiced organizing code using modules and an MVC-style approach, separating logic, data, and DOM rendering into different responsibilities.

I also improved my understanding of:

* DOM manipulation
* Event delegation
* Dynamic rendering
* Reusable helper functions
* Modal management
* Application state handling
* Import/export modules with Webpack

One of the biggest lessons from this project was learning how important code organization becomes as projects grow larger.

## Challenges

Some of the challenges I encountered were:

* Managing modal behavior
* Handling active project rendering
* Preventing duplicated logic
* Dynamically updating UI elements
* Debugging rendering issues

Solving these problems helped improve my debugging and problem-solving skills.

## Reflection

This project felt like my first real JavaScript application. It helped me become more comfortable building larger projects without relying heavily on tutorials.
